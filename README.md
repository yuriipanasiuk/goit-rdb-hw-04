## Аналіз результатів JOIN

### Результат `INNER JOIN`

Початковий запит із використанням `INNER JOIN` повертає **518 рядків**.

### Результат `LEFT JOIN`

Після заміни операторів `INNER JOIN` на `LEFT JOIN` кількість рядків **не змінилася** та залишилася **518**.
Це означає, що всі записи з лівої таблиці (`order_details`) мають відповідні записи у таблицях, які приєднуються.
Тому `LEFT JOIN` не додав нових рядків, і результат залишився таким самим, як і при використанні `INNER JOIN`.

### Результат `RIGHT JOIN`

При використанні `RIGHT JOIN` кількість рядків також **залишилася 518**.
Це означає, що в таблиці, яка знаходиться праворуч від `RIGHT JOIN`, немає додаткових записів без відповідних записів у попередніх таблицях, які могли б збільшити кількість результатів.

### Висновок

У наших даних заміна `INNER JOIN` на `LEFT JOIN` або `RIGHT JOIN` **не вплинула на кількість отриманих рядків**.
У всіх випадках результат становить **518 рядків**.
Таким чином, `INNER JOIN`, `LEFT JOIN` та `RIGHT JOIN` можуть повертати однакову кількість рядків, якщо між таблицями існують відповідні записи для всіх рядків, які беруть участь у з'єднанні.
У нашому випадку всі використані варіанти `JOIN` повернули **518 рядків**.
